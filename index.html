🎯 好技能（SKILL.md）的 6 個原則

技能能不能「被叫出來、做得好」，關鍵在下面這幾點。

🔑
description 是靈魂

AI 靠它決定要不要用這技能。務必寫清楚「做什麼」＋「何時用（觸發詞）」。

🏷️
name 用小寫連字號

例 excel-merger，會是資料夾名，也讓工具好辨識。

📋
步驟具體可執行

把流程逐步寫清楚，AI 照做才穩定，不會每次結果不一樣。

🚧
寫清楚邊界

要避免什麼、合規紅線、邊角情況先講，減少出錯。

🎯
一技能一件事

範圍聚焦才好觸發、好維護；太雜的技能不如拆成幾個。

🧪
附範例更穩

給一個輸入 → 理想輸出的例子，品質立刻拉高。

01｜🔁 舊 Gem 一鍵轉 Skill

在 Gemini 開啟既有 Gem →「編輯」→ 將「指令／Instructions」完整貼入下方。系統立即產生標準 Agent Skill 的 SKILL.md。本功能為本機規格化轉換，不需 API Key；建議人工檢查觸發描述及指令內容。

① 匯入舊 Gem 設定

保留你原有的角色、任務、步驟、限制與輸出要求，不會任意刪減。
小寫英數字，以半形連字號 - 分隔；留空會使用 my-gem-skill。
🔒 請先刪除舊指令內的 API Key、密碼、學生個資與其他機密內容；此工具只在目前瀏覽器轉換，但會使用本機儲存空間保存草稿。

02｜一次性轉換指令

將下列完整指令複製到 AI 對話中，要求協助整理多個 Gems。此區為指令範本，不會自動存取 Gemini 帳戶。

🔐 使用前提｜Spark 付費方案＋Google 雲端硬碟

這份「批次轉換所有 Gems」指令採用 Spark 付費使用情境，需先確認你的付費方案已開通相關功能，並透過 「@Google 雲端硬碟」 啟用 Google Drive 資料存取，才有機會讀取已授權的檔案並進行整理。

  1. 登入具備所需 Spark 功能的付費帳戶，開啟支援此功能的對話。
  2. 在對話輸入 @Google 雲端硬碟，選取並授權 Google 雲端硬碟連結。
  3. 確認欲轉換的 Gem 指令及知識附件已放在可存取的雲端硬碟位置，並授予必要權限。
  4. 點擊「一鍵複製完整指令」，貼入該對話執行；核對產出的 SKILL.md、references 與 ZIP。

注意：付費並不保證 AI 能直接列出所有私人 Gems；Google Drive 授權僅能存取該連線有權讀取的資料。「@Google 雲端硬碟」選項、Spark 方案權限與匯入格式依當下平台實際提供為準。

展開／收合：一次性轉換指令全文 
【執行前提與操作方式】
本指令適用於已開通所需 Spark 功能的付費方案。先在支援的對話中使用「@Google 雲端硬碟」啟用並授權雲端硬碟；將要處理的 Gem 指令及知識附件置於可存取位置後再執行。請先確認你實際能讀到哪些檔案，不得宣稱能直接取得未授權或未提供的私人 Gems。如缺少內容，列出待補資料並請使用者提供。

你是一位精通工作流自動化、知識庫管理與 Google Gemini 生態系的專家。請將我目前現有的所有自訂 Gems 進行完整備份、轉換與結構化打包，轉換為符合「Gemini Spark 技能（Skills）」標準規範的資料夾架構，並集合成一個 ZIP 壓縮檔供我下載。

---

### 檔案與目錄結構規範（Gemini Spark 標準架構）：

請為「每一個 Gem」建立專屬的獨立子資料夾，命名為 `[Gem名稱]/`，每個資料夾內必須包含以下規格：

1. **技能定義主檔（`SKILL.md`）**：
   - 檔名必須固定為 `SKILL.md`。
   - 將該 Gem 的系統指示（System Instructions）轉化為標準 Markdown 格式，結構需包含：
     - `# [Gem 名稱] 技能定義`
     - `## 觸發時機與目標 (Trigger & Objective)`：明確定義何時調用此技能及解決的具體任務。
     - `## 角色與專業設定 (Persona & Expertise)`：明確定義模型角色定位與語氣風格。
     - `## 執行流程與處理邏輯 (Step-by-Step Workflow)`：分步驟列出推理、分析或產出流程。
     - `## 輸入/輸出規範與限制 (Constraints & Output Format)`：明確規範產出格式（如 Markdown 結構、特定欄位等）與禁止事項。
     - `## 參考知識庫索引 (Knowledge Base Index)`：條列並簡述 `references/` 目錄下檔案的對應功能與使用情境。

2. **參考文件資料夾（`references/`）**：
   - 資料夾名稱固定為 `references/`。
   - 完整匯出該 Gem 中所有上傳的參考檔案與知識庫文件（如 `.pdf`、`.docx`、`.txt`、`.csv` 等），保留原始檔名與副檔名放入此資料夾。

---

### 最終交付要求：

1. **結構預覽**：在對話中先以 Markdown 樹狀圖（Tree view）呈現打包後的目錄架構。
2. **ZIP 壓縮檔**：將所有 Gem 資料夾集合壓縮為一個 `.zip` 檔，確保解壓縮後可直接無縫匯入/上傳至 Gemini Spark 作為自訂技能使用，並提供下載。
提醒：此範本要求匯出所有 Gems 和附件；AI 只有在具備相應存取權限、且確實取得資料時才能完成。ZIP 是否可直接匯入 Gemini Skills，仍須依 Google 的實際匯入規範確認。請勿提供密碼、API Key 或未授權的個人資料。
